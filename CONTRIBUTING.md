# Contributing

This project welcomes bounded technical criticism, reproducibility reports,
and corrections.

## Before submitting

1. Read `RELEASE_BOUNDARY.md`.
2. Reproduce the relevant result using the documented commands.
3. State the exact version, environment, inputs, and observed output.
4. Separate evidence from interpretation.
5. Disclose relevant financial, professional, or personal conflicts.

## Review categories

- Blocking: invalidates a central method, result, or release claim.
- Major: materially changes interpretation, reproducibility, or scope.
- Minor: improves clarity or implementation without changing the central claim.
- Editorial: wording, formatting, or citation correction.

Use the technical-review issue form for manuscript or protocol findings. Use
the replication-report form for independent reproduction attempts.

Submitting a review does not imply endorsement. Review credit will be given
only with the reviewer’s consent.
